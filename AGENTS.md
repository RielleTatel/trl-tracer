# trl-tracer

Trace every readiness claim to the page that proves it. Evidence-backed TRL assessment of
technical reports for the 2nd APCTT Hackathon 2026. The plan is in `PLAN.md`.

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
